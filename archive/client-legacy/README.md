# Archived Client Legacy Files

This folder keeps old client-side reference files that are no longer part of
the active runtime but may still help when comparing history or recovering
older patterns.

Archived items
- `src.jsx` — legacy map screen prototype replaced by the code under `client/src`.
- `postcss.config.js.bak` — backup of an old PostCSS config.

Active client code now lives in `client/`.
